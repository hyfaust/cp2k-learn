## 1. 高斯基组原理

### 1.1 线性组合原子轨道 (LCAO)

在分子量子力学计算中，分子轨道 φᵢ(r) 用一组预定义的基函数 {χ_μ(r)} 的线性组合来展开：

```
φᵢ(r) = Σ_μ c_μᵢ χ_μ(r)
```

其中：
- χ_μ(r) 是第 μ 个基函数
- c_μᵢ 是展开系数（待求解的未知数）
- 求和对所有基函数进行

基函数越多，理论上能描述的电子结构越精确（变分原理保证），但计算成本也越高。因此，选择合适的基组是平衡精度和效率的关键。

### 1.2 高斯型轨道 (GTO)

基函数 χ_μ(r) 的具体数学形式决定了基组的类型。在量子化学中，最常用的是**高斯型轨道 (Gaussian Type Orbitals, GTO)**。

GTO 的笛卡尔形式为：

```
χ(r) = N · (x-a_x)^l_x · (y-a_y)^l_y · (z-a_z)^l_z · exp(-α|r-A|²)
```

其中：
- N 是归一化常数
- (a_x, a_y, a_z) 是基函数中心（即原子 A 的坐标）
- l_x, l_y, l_z 是角动量量子数（l_x + l_y + l_z = l，决定轨道类型）
- α 是指数参数（控制高斯函数的"宽度"，α 大 = 窄函数，α 小 = 宽函数）

**轨道类型与角动量**：

| 总角动量 l | 名称 | 笛卡尔分量数 |
|-----------|------|-------------|
| 0 | s 轨道 | 1 |
| 1 | p 轨道 | 3 (px, py, pz) |
| 2 | d 轨道 | 6 (笛卡尔) 或 5 (纯球谐) |
| 3 | f 轨道 | 10 (笛卡尔) 或 7 (纯球谐) |

GTO 相比 Slater 型轨道 (STO) 的优点：两个高斯函数的乘积仍然是高斯函数，因此多中心积分可以解析计算，效率远高于 STO。

GTO 的缺点：在原子核附近（r→0）和远处（r→∞）的行为不如 STO 真实。为弥补这一缺陷，实际使用时会用多个不同 α 的高斯函数的线性组合（收缩）来描述一个原子轨道。

### 1.3 收缩方案 (Contraction Scheme)

一个**收缩高斯基函数**是多个**原始高斯基函数 (primitive GTO)** 的线性组合：

```
χ_μ(r) = Σ_k d_kμ · g_k(r)
```

其中：
- g_k(r) 是原始高斯基函数（具有固定的指数 α_k）
- d_kμ 是收缩系数
- 求和中的项数称为**收缩长度 (contraction length)**

例如，一个双 zeta 基组中的 s 轨道可能由 4 个原始高斯函数收缩而成：

```
χ₁(s) = d₁·g₁(α₁) + d₂·g₂(α₂) + d₃·g₃(α₃) + d₄·g₄(α₄)   ← 内层收缩
χ₂(s) = d₅·g₅(α₅) + d₆·g₆(α₆)                              ← 外层收缩
```

- χ₁ 描述原子核附近区域（内层轨道特征）
- χ₂ 描述化学键区域（外层/价轨道特征）
- 两个收缩函数一起，允许轨道在原子间形成化学键时灵活"呼吸"

### 1.4 原始函数与收缩函数的区分

理解以下区别对后续很重要：

| 概念 | 英文 | 含义 |
|------|------|------|
| 原始函数 | Primitive GTO | 单个高斯函数，由指数 α 定义 |
| 收缩函数 | Contracted GTO | 多个原始函数的线性组合 |
| 基函数 | Basis function | 实际参与变分计算的函数（即收缩函数） |
| 基组大小 | Basis set size | 收缩函数的总数，决定 Kohn-Sham 矩阵的维度 |

## 2. CP2K基组命名规则

### 2.1 命名格式

CP2K 的基组名称遵循统一的命名格式：

```
[精度等级]-[赝势类型]-[泛函名]
```

例如：`DZVP-GTH-PADE`

- **精度等级**：描述基组大小和质量
- **赝势类型**：通常是 GTH
- **泛函名**：基组和赝势针对哪个泛函优化

### 2.2 精度等级详解

| 等级 | 全称 | 含义 | 基函数数量 | 适用场景 |
|------|------|------|-----------|----------|
| **SZV** | Single Zeta Valence | 最小基组 | 1 个收缩/价轨道 | 快速初筛、定性分析 |
| **DZV** | Double Zeta Valence | 双 zeta | 2 个收缩/价轨道 | 较好的性价比 |
| **DZVP** | DZ Valence Polarized | 双 zeta + 极化 | DZV + 极化函数 | **推荐的日常选择** |
| **TZV** | Triple Zeta Valence | 三 zeta | 3 个收缩/价轨道 | 高精度计算 |
| **TZVP** | TZ Valence Polarized | 三 zeta + 极化 | TZV + 极化函数 | 高精度分子计算 |
| **TZV2P** | TZ Valence 2-Polarized | 三 zeta + 2 组极化 | TZV + 2组极化函数 | 精确计算、测试 |

**"Valence" (V) 的含义**：基组只用于描述价电子轨道。核心电子已被赝势处理，不需要基函数来描述。

**"Polarized" (P) 的含义**：包含极化函数。极化函数是比最高价轨道角动量高一级的函数：
- 对 H（价层 s），极化函数是 p 轨道
- 对 O（价层 s, p），极化函数是 d 轨道
- 对 Si（价层 s, p），极化函数是 d 轨道
- 对过渡金属（价层 s, p, d），极化函数是 f 轨道

极化函数的重要性：没有极化函数，分子中的原子轨道无法变形。例如，H₂O 中氧原子的 p 轨道在形成 O-H 键时需要变形（sp³ 杂化），极化函数（d 轨道）允许这种变形。

### 2.3 MOLOPT 基组

CP2K 还提供一组特殊的 **MOLOPT (Molecular Optimized)** 基组：

```
DZVP-MOLOPT-SR-GTH-PBE
```

MOLOPT 基组的特点：
- **专门为分子和有限体系优化**（而非周期性体系）
- **"SR" 表示 Short-Range**：基函数设计为在较短范围内衰减，适合分子动力学中常见的中等大小盒子
- 通常具有更紧凑的收缩形式，效率更高
- 对于气相分子和溶液体系，MOLOPT 基组通常比标准基组更高效

### 2.4 如何选择基组

根据计算目的选择基组的推荐：

```
初步测试/调试     →  SZV-GTH-PADE (或 SZV-GTH-PBE)
日常DFT计算       →  DZVP-GTH-PBE (或 DZVP-MOLOPT-SR-GTH-PBE)
高精度单点能      →  TZV2P-GTH-PBE (或更大)
从头算分子动力学  →  DZVP-MOLOPT-SR-GTH-PBE
```

**实用建议**：
1. 先用小基组（SZV）调试输入文件，确认正确后再用大基组正式计算
2. 对比不同基组的结果，确保结果已收敛（本章的核心目标）
3. 选择与你的泛函匹配的基组系列

## 3. 赝势详解

### 3.1 为什么需要赝势

在量子化学计算中，赝势 (Pseudopotential) 或有效核势 (Effective Core Potential, ECP) 的核心目的是：

**将核心电子的效应用一个有效势替代，只显式处理价电子。**

以硅 (Si) 为例：

```
全电子：    1s² 2s² 2p⁶ 3s² 3p²  =  14 个电子
赝势处理：  [1s² 2s² 2p⁶] 3s² 3p²  =  4 个价电子（10个核心电子被赝势替代）
```

这样做有三个主要好处：

#### 好处一：减少电子数

电子数从 14 减少到 4，Kohn-Sham 矩阵维度大幅减小，对角化成本从 O(N³) 的角度来看大大降低。

#### 好处二：消除核心态振荡

核心电子的波函数在原子核附近有剧烈的空间振荡（类似氢原子的 1s, 2s, 3s...在 r→0 处的节点），需要极细的实空间网格才能准确描述。赝势使价电子波函数变得光滑，可以用较粗的网格准确描述。

#### 好处三：减少相对论效应

核心电子运动速度快，需要考虑相对论效应。赝势将这些效应隐式包含在势的参数中，避免了显式的相对论计算。

### 3.2 模守恒赝势 (Norm-Conserving Pseudopotentials)

CP2K 使用 **GTH (Goedecker-Teter-Hutter)** 赝势，属于模守恒赝势家族。模守恒的条件是：

```
∫₀^rc |R_l(r)|² dr = ∫₀^rc |R_l^PS(r)|² dr
```

即赝波函数和真实波函数在截断半径 r_c 内包含的电子数相同。这一条件保证了赝势的可移植性 (transferability)——在不同化学环境中都能给出准确结果。

### 3.3 GTH 赝势的结构

GTH 赝势使用解析形式，由以下几部分组成：

```
V_l(r) = V_local(r) + Σ_lm |Y_lm> ΔV_l(r) <Y_lm|
```

- **局域部分 V_local**：对所有角动量通道相同，长程部分为 -Z_val/r（类库仑势）
- **非局域部分 ΔV_l**：与角动量 l 有关的短程修正

GTH 赝势的参数（截断半径 r_c、高斯展宽参数、系数等）已针对各种交换关联泛函预优化，存储在 CP2K 的 `GTH_POTENTIALS` 文件中。

### 3.4 赝势与泛函的匹配

**这是初学者最容易犯的错误之一**。GTH 赝势是针对特定泛函参数化的，因此必须使用匹配的赝势和泛函：

| 交换关联泛函 | 对应赝势前缀 | 对应基组前缀 |
|-------------|-------------|-------------|
| PADE (LDA) | GTH-PADE | xxx-GTH-PADE |
| PBE (GGA) | GTH-PBE | xxx-GTH-PBE |
| BLYP (GGA) | GTH-BLYP | xxx-GTH-BLYP |
| PBE0 (Hybrid) | GTH-PBE | xxx-GTH-PBE（与PBE相同）|

> **重要**：使用 PBE 赝势 + PADE 泛函是错误的！这会导致赝势参数和实际使用的泛函不一致，结果不正确且可能不收敛。

### 3.5 价电子数 (qN)

赝势文件名中的 `qN` 标记表示该赝势处理的价电子数：

```fortran
! 常见元素的价电子配置
! H:  1s¹           → q1
! C:  [He] 2s²2p²   → q4
! N:  [He] 2s²2p³   → q5
! O:  [He] 2s²2p⁴   → q6
! Si: [Ne] 3s²3p²   → q4
! Fe: [Ar] 3d⁶4s²   → q8 或 q16（取决于核心/价的划分）
```

对于过渡金属，可能有多种赝势选择（不同的核心/价划分），需要根据具体计算目标选择。

## 4. 基组收敛性

### 4.1 什么是基组收敛性

基组收敛性 (Basis Set Convergence) 指的是：随着基组质量的提高（SZV → DZVP → TZV2P → ...），计算结果趋近于基组极限 (Complete Basis Set, CBS) 的过程。

理想情况下，我们希望用无穷大的基组来描述电子波函数。实际计算中，我们只能用有限大小的基组。因此，必须验证计算结果是否已随基组大小收敛。

### 4.2 收敛性检验方法

#### 方法一：系统性基组提升

```
SZV → DZV → DZVP → TZV → TZVP → TZV2P → ...
```

观察总能量或感兴趣的物理量（反应能、振动频率等）的变化。当进一步增大基组不再显著改变结果时，认为收敛。

#### 方法二：外推到 CBS 极限

利用已知的基组收敛速率，数学外推到完全基组极限：

```
E_X = E_CBS + A / X^3
```

其中 X 是 zeta 数（双 zeta = 2，三 zeta = 3，四 zeta = 4）。

#### 方法三：基组重叠误差 (BSSE) 校正

当计算分子间相互作用（如结合能）时，使用不同分子的基组可以相互"借用"（基组重叠），导致结合能被高估。Counterpoise 校正可以消除这一误差。

### 4.3 基组收敛的预期行为

对于总能量，基组收敛通常呈现以下规律：

| 基组等级 | 典型总能量变化（相对于下一等级）|
|---------|--------------------------|
| SZV → DZVP | 数百 meV |
| DZVP → TZV2P | 数十 meV |
| TZV2P → QZV3P | 数 meV |

**关键观察**：
1. 每次提升 zeta 数，能量降低（变分原理保证）
2. 能量降低的幅度逐级递减
3. 对于实际应用（反应能、几何优化），DZVP 通常已经足够
4. 高精度要求（< 1 meV/atom）需要 TZV2P 或更大基组

### 4.4 基组收敛与截断能收敛的区别

CP2K 中有两个独立的收敛参数：

| 参数 | 含义 | 影响 |
|------|------|------|
| **基组大小** | 高斯基函数的数量 | Kohn-Sham 矩阵维度 |
| **CUTOFF** | 平面波截断能 | 实空间网格分辨率 |

这两个参数的收敛是**独立**的：
- 基组决定能描述多复杂的波函数
- CUTOFF 决定密度和势在网格上能表示多精细

本章关注基组收敛，下一章 (Chapter 4) 关注 CUTOFF 收敛。

## 5. BASIS_SET和GTH_POTENTIALS文件

### 5.1 文件位置

CP2K 自带完整的基组和赝势数据库，通常位于：

```bash
# 查找 CP2K 数据目录
echo $CP2K_DATA_DIR

# 或者查找 CP2K 安装路径
which cp2k.popt
# 假设输出为 /usr/local/bin/cp2k.popt
# 数据目录可能在 /usr/local/share/cp2k/data/ 或类似位置
```

在输入文件中指定：

```fortran
&BASIS_SET_FILE_NAME BASIS_SET          ! 基组数据文件
&POTENTIAL_FILE_NAME GTH_POTENTIALS     ! 赝势数据文件
```

CP2K 会在以下位置按优先级查找这些文件：
1. 当前工作目录
2. `CP2K_DATA_DIR` 环境变量指定的目录
3. CP2K 编译时默认的数据目录

### 5.2 BASIS_SET 文件格式

`BASIS_SET` 文件中的每个基组条目格式如下（以 DZVP-GTH-PADE 的 O 为例）：

```
O DZVP-GTH-PADE
  2
  2 0 1 4 2 2
        exponents           contraction coefficients
  ...
  3 2 1 1 1
        exponents           contraction coefficients
  ...
```

各行含义：
- 第 1 行：元素符号 + 基组名称
- 第 2 行：电子壳层数（set 数）
- 随后每个块：
  - 第 1 个数字：主量子数 n
  - 第 2 个数字：角动量 l（0=s, 1=p, 2=d...）
  - 第 3 个数字：该角动量通道的收缩函数个数
  - 第 4 个数字：原始高斯函数的个数
  - 后续数字：与极化函数相关的标记
  - 接下来的行：指数和收缩系数

> **通常不需要手动编辑这些文件**，除非你要创建自定义基组。

### 5.3 GTH_POTENTIALS 文件格式

赝势文件中的条目格式类似：

```
O GTH-PADE-q6
  2    4
  0.20000000    1    -8.47990642
                1     0.72986802    2
  0.20000000    2     2.67763000
                1     0.45218000    3
```

- 元素符号 + 赝势名称
- 非局域通道数 + 局域通道参数个数
- 局域势参数
- 各角动量通道的非局域势参数

### 5.4 创建自定义基组/赝势

在某些特殊情况下，你可能需要：
1. 使用 CP2K 数据库中没有的元素
2. 使用自定义优化的基组
3. 使用其他来源的赝势

可以创建本地的基组/赝势文件，然后在输入中指定：

```fortran
BASIS_SET_FILE_NAME  BASIS_SET  MY_BASIS_SET     ! 同时搜索两个文件
POTENTIAL_FILE_NAME  GTH_POTENTIALS  MY_POTENTIALS
```

多个文件名用空格分隔，CP2K 会依次搜索。

## 6. GAPW方法简介

### 6.1 GPW vs GAPW

CP2K 的 QUICKSTEP 模块提供两种核心方法：

| 特性 | GPW | GAPW |
|------|-----|------|
| 全称 | Gaussian and Plane Waves | Gaussian Augmented Plane Waves |
| 赝势 | 必需 | 可选（支持全电子） |
| 核心电子 | 被赝势处理 | 可以显式计算 |
| 计算效率 | 高 | 较低 |
| 适用场景 | 大体系、MD | 核心性质、全电子计算 |
| 方法关键词 | `METHOD Quickstep`（默认） | 需在 `&QS` 中设置 |

### 6.2 什么时候使用 GAPW

GAPW 方法在以下场景中更合适：

1. **全电子计算**：当需要考虑核心电子效应时（如 X 射线光谱、核心能级位移）
2. **核心性质**：NMR 化学位移、EPR 超精细耦合常数等
3. **高精度基准计算**：不使用赝势的全电子计算可以提供无赝势误差的结果
4. **赝势不可用的情况**：某些元素或泛函没有对应的 GTH 赝势

### 6.3 GAPW 的基本用法

```fortran
&QS
  METHOD GAPW
  &GAPW
    ALPHA0_TYPE ALL
    QUADRATURE  SD
  &END GAPW
&END QS
```

全电子计算时不需要在 `&KIND` 中指定 `POTENTIAL`，但需要使用全电子基组（如 `cc-pVDZ` 或 `aug-cc-pVDZ`）。

### 6.4 GPW 方法（默认，本教程使用）

在大多数情况下，使用默认的 GPW 方法即可：

```fortran
&QS
  EPS_DEFAULT 1.0E-10   ! 精度控制
&END QS
```

不需要额外设置 `METHOD`（默认就是 GPW）。

## 7. 三个输入文件详解

本章提供了三个水分子计算输入文件，唯一区别在于使用的基组不同：

### 7.1 H2O_szv.inp — SZV 最小基组

```fortran
BASIS_SET SZV-GTH-PADE
POTENTIAL GTH-PADE-q6    ! O
POTENTIAL GTH-PADE-q1    ! H
```

**SZV (Single Zeta Valence)** 是最小基组：
- 每个价轨道只用一个收缩函数描述
- 没有极化函数
- 基函数数量最少，计算最快
- 精度有限，适合定性分析

对于水分子 (H₂O)：
- O: 1 个 s + 1 个 p (3个方向) = 4 个基函数
- H: 1 个 s = 1 个基函数
- 总基函数：4 + 1 + 1 = 6 个

### 7.2 H2O_dzvp.inp — DZVP 双 zeta 基组

```fortran
BASIS_SET DZVP-GTH-PADE
POTENTIAL GTH-PADE-q6    ! O
POTENTIAL GTH-PADE-q1    ! H
```

**DZVP (Double Zeta Valence Polarized)** 是推荐的日常基组：
- 每个价轨道用两个收缩函数描述（双 zeta）
- 包含一组极化函数（d 轨道对 O，p 轨道对 H）
- 精度和效率的良好平衡

对于水分子：
- O: 2 个 s + 2 个 p + 1 个 d = 更多基函数
- H: 2 个 s + 1 个 p = 更多基函数
- 总基函数显著多于 SZV

### 7.3 H2O_tzv2p.inp — TZV2P 三 zeta 基组

```fortran
BASIS_SET TZV2P-GTH-PADE
POTENTIAL GTH-PADE-q6    ! O
POTENTIAL GTH-PADE-q1    ! H
```

**TZV2P (Triple Zeta Valence 2-Polarized)** 是高精度基组：
- 每个价轨道用三个收缩函数描述（三 zeta）
- 包含两组极化函数（2P）
- 适合高精度基准计算
- 计算成本显著高于 DZVP

### 7.4 三个文件的对比

| 参数 | H2O_szv.inp | H2O_dzvp.inp | H2O_tzv2p.inp |
|------|-------------|--------------|----------------|
| 基组 | SZV-GTH-PADE | DZVP-GTH-PADE | TZV2P-GTH-PADE |
| 赝势 | GTH-PADE | GTH-PADE | GTH-PADE |
| 泛函 | PADE | PADE | PADE |
| 其他参数 | 完全相同 | 完全相同 | 完全相同 |

唯一的差异是基组名称。这样设计是为了**隔离变量**，纯粹观察基组大小对结果的影响。

## 8. 实战脚本

### 8.1 convergence_test.sh 脚本详解

`convergence_test.sh` 是一个自动化脚本，用于依次运行三个基组的计算并汇总结果。

#### 脚本结构

```bash
#!/bin/bash
set -e  # 遇到错误立即退出

# CP2K 可执行文件和进程数
CP2K_EXE="cp2k.popt"
NP=1

# 定义基组列表
BASIS_SETS=("SZV" "DZVP" "TZV2P")
INPUT_FILES=("H2O_szv.inp" "H2O_dzvp.inp" "H2O_tzv2p.inp")
```

#### 主循环

```bash
for i in "${!BASIS_SETS[@]}"; do
    BASIS="${BASIS_SETS[$i]}"
    INPUT="${INPUT_FILES[$i]}"
    OUTPUT="H2O_${BASIS,,}.out"

    # 运行 CP2K
    "$CP2K_EXE" -o "$OUTPUT" "$INPUT"

    # 提取总能量
    ENERGY=$(grep "ENERGY| Total FORCE_EVAL" "$OUTPUT" | tail -1 | awk '{print $NF}')
done
```

#### 结果汇总

脚本会打印一个漂亮的表格，包含：
- 每个基组的总能量
- 相邻基组之间的能量差（Hartree 和 eV）

### 8.2 使用方法

```bash
# 1. 确保脚本有执行权限
chmod +x convergence_test.sh

# 2. 如需要，修改 CP2K_EXE 变量指向正确的可执行文件
# 例如: CP2K_EXE="cp2k.psmp"

# 3. 运行脚本
./convergence_test.sh
```

### 8.4 结果分析

从预期结果可以观察到：

1. **SZV → DZVP 的能量下降** 远大于 **DZVP → TZV2P 的能量下降**
2. 这说明 DZVP 已经捕获了大部分基组相关的能量贡献
3. 对于大多数化学应用（反应能、几何优化、分子动力学），DZVP 已经足够
4. 只有在追求 meV 级精度时，才需要使用 TZV2P 或更大的基组

### 8.5 扩展练习

修改脚本以添加更多基组（需要对应输入文件）：

```bash
# 可以在 BASIS_SETS 和 INPUT_FILES 数组中添加更多条目
BASIS_SETS=("SZV" "DZV" "DZVP" "TZV" "TZVP" "TZV2P")
```

或者，创建一个更通用的脚本，自动从单个模板生成不同基组的输入文件：

```bash
# 使用 sed 从模板生成输入
for BASIS in SZV DZVP TZV2P; do
    sed "s/BASISNAME/${BASIS}-GTH-PADE/g" template.inp > "H2O_${BASIS}.inp"
done
```

### 8.6 自动化最佳实践

1. **始终记录参数**：在结果文件中记录使用的基组、泛函、CUTOFF 等
2. **使用一致的条件**：除目标参数外，所有其他条件保持一致
3. **检查收敛**：不仅检查能量，还要检查 SCF 收敛步数
4. **保留所有输出**：不要删除中间结果，方便后续检查
5. **使用版本控制**：将输入文件和脚本纳入 git 管理

## 总结

| 概念 | 关键要点 |
|------|---------|
| 基组 | 定义 Kohn-Sham 轨道的展开方式 |
| GTO | 高斯型轨道，CP2K 使用的基函数类型 |
| zeta 数 | 描述每个价轨道用几个收缩函数，越多越精确 |
| 极化函数 | 允许轨道变形，对化学键描述很重要 |
| GTH 赝势 | Goedecker-Teter-Hutter 模守恒赝势 |
| 赝势匹配 | 赝势必须与泛函和基组匹配 |
| 基组收敛 | 系统性增大基组直到结果稳定 |
